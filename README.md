# Sistema Integral de Gestión de Clientes, Servicios y Reservas – Software FJ

## Descripción del proyecto

Software FJ es un sistema desarrollado en Python que permite gestionar clientes, servicios y reservas mediante programación orientada a objetos.

El programa permite registrar clientes, consultar servicios disponibles, crear reservas, confirmar o cancelar reservas y calcular los costos de los servicios.

## Objetivo

Desarrollar un sistema modular y extensible aplicando los principios de programación orientada a objetos, como abstracción, herencia, encapsulamiento y polimorfismo, además del manejo de excepciones.

## Tecnologías utilizadas

- Python.
- Visual Studio Code.
- Git y GitHub.
- Módulo unittest para las pruebas automáticas.

## Estructura del proyecto

- `main.py`: programa principal y menú.
- `clases/`: contiene las clases de clientes, servicios y reservas.
- `utilidades/`: contiene las excepciones personalizadas y la configuración de registros.
- `pruebas/`: contiene las pruebas automáticas del sistema.
- `logs/`: almacena los registros de eventos y errores.

## Servicios disponibles

1. Reserva de salas.
2. Alquiler de equipos.
3. Asesoría técnica.

## Ejecución del programa

Desde la terminal, dentro de la carpeta principal del proyecto, ejecutar:

```bash
python main.py
```

## Ejecución de las pruebas

Para ejecutar las pruebas automáticas, utilizar:

```bash
python -m unittest pruebas.test_sistema -v
```

El proyecto cuenta con 17 pruebas automáticas que permiten verificar el funcionamiento de las clases, los servicios, los costos y las reservas.
